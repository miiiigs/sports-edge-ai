## Goal For The First Five Focused Days

By the end of five focused days, the aim is not to prove a betting edge.

The aim is to produce:

- a real working foundation instead of only documents;
- a structured MLB reverse-engineering workflow;
- immediate football data reconnaissance;
- a first football historical intake spine;
- a shortlist of usable odds/data sources;
- the smallest honest prototype path for trial outputs;
- and one narrow measurable market-validation lane.

## Day 1 - Evidence, direction, and research setup

Focus:

- lock the direction from the meeting;
- normalize the MLB sample;
- define hypotheses and data requirements;
- assess whether the Pack starter code can be rebuilt from the PDF.

Outputs:

- Pack-code recoverability assessment;
- MLB 22-pick dataset;
- hypothesis document;
- data requirements matrix;
- project tracking documents.

## Day 2 - Pack recovery and data-source reconnaissance

Outputs:

## What We Should Realistically Have After Five Days

- Pack starter code recovered into repo files, at least partially runnable;
- recovered tests passing and demo baseline verified;
- a structured and growing MLB reconstruction dataset;
- football data reconnaissance started with an actual historical/live source split;
- first football historical intake artifact generated;

- a clear immutable history path for paper/shadow outputs;
- a narrow experiment path defined for testing one angle cheaply;
- documented blockers and next steps.

## What We Should Not Promise After Five Days

- all 50 agents;
- complete football or tennis production implementation;
- full historical market reconstruction for every MLB pick;
- validated bookmaker-strategy conclusions.
